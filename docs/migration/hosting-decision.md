Only Games Web and Sports Web have GitHub Pages sites. Those two new repositories are public by explicit user decision. The other eight repositories remain private. Canonical Games owns immutable archives in its own GitHub Releases. Games Web serves the accepted game library under /game-library/ as part of its own static site snapshot. A game-only publication composes already accepted host bytes with accepted game bytes locally and invokes Games Web's exact-artifact workflow, without rebuilding the host.
